¿Cómo configurar mi Google Client ID?

Para que cada usuario pueda guardar sus registros en su propia hoja BiblioTrack_Registros de Google Sheets desde GitHub Pages, sigue estos pasos gratuitos una sola vez:

  1. Entra a Google Cloud Console y crea un proyecto nuevo.
  2. Ve a APIs y servicios → Biblioteca y habilita Google Drive API y Google Sheets API.
  3. Ve a Pantalla de consentimiento de OAuth (tipo Externo), pon el nombre de tu app, tu correo y añade el alcance .../auth/drive.file (y añade a tus amigos en Usuarios de prueba si la app está en modo prueba).
  4. Ve a Credenciales → Crear credenciales → ID de cliente de OAuth (tipo Aplicación web).
  5. En Orígenes autorizados de JavaScript, agrega tu dominio de GitHub Pages (ej. https://tuusuario.github.io).
  6. Copia el ID de cliente y pégalo en la variable GOOGLE_CLIENT_ID al inicio del código JavaScript de este archivo.
